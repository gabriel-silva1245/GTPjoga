

O GTPjoga é um projeto pessoal de desenvolvimento web criado para disponibilizar uma plataforma simples e intuitiva para  baixar jogos.

O projeto foi desenvolvido com foco em interface responsiva, organização de conteúdo, permitindo navegar pelo catálogo de jogos, e acessar as opções de download.


* Ferramentas utilizadas 

* HTML5
* CSS3
* GitHub Pages

Funcionalidades

* Catálogo de jogos
* Interface responsiva
* Compatibilidade com diferentes dispositivos
* Links para download
* Interface personalizada

Projeto online

Acesse o GTPjoga:

Este projeto foi desenvolvido como forma de praticar e aprimorar conhecimentos em Front-End, principalmente na criação de interfaces, organização de páginas, estilização com CSS O projeto continua em desenvolvimento.
